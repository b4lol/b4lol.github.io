B4Assistant

A rooted Android Quick Settings toolkit with a Material 3 Expressive home screen.

View on GitHub Download APK

About the project

B4Assistant puts powerful root actions one swipe away: Quick Settings tiles for screenshots, Wi-Fi, mobile data, private DNS, Caffeine and screen locking — all wrapped in a coordinated light and dark Material 3 Expressive palette. Background root commands run with timeouts, bounded output and cached root status.

The project is a fork of MeowAssistant (MIT), repackaged as com.b4lol.assistant so it installs separately from the original app. Release tags build a minified, resource-shrunk, signed APK published with a SHA-256 checksum.

Highlights

  • Quick Settings tiles Screenshots, Wi-Fi, mobile data, private DNS, Caffeine and screen locking — straight from the notification shade.
  • Module shortcuts One-tap shortcuts for QuietKill and Integrity-Box module scripts.
  • Material 3 Expressive A coordinated light and dark palette built with Jetpack Compose Material 3 Expressive.
  • Safe root execution Background root commands with timeouts, bounded output and cached root status.

Requirements

Android 10 or later, root access for system actions and scripts, and the optional modules for their respective shortcuts.

brim

A modern, pure-Rust package manager and app store for Fedora and Debian — DNF5, APT, COPR and Flatpak behind one engine.

View on GitHub Releases

About the project

brim unifies DNF5 (official Fedora RPMs), APT (Debian/Ubuntu packages), COPR (community projects) and Flatpak (Flathub) behind a single async engine, and exposes it through three frontends: a terminal CLI, a native GTK4/Libadwaita desktop app and a glassmorphic web dashboard with a REST API. On any given machine only the available backends activate — on Fedora that is DNF5 + Flatpak (+ COPR), on Debian/Ubuntu APT + Flatpak.

Highlights

  • One search across everything Merged, relevance-sorted results from Fedora repos, COPR and Flathub in a single query.
  • Three frontends, one engine A single binary hosts the CLI, the GTK4 GUI and the web UI over one shared core; missing tools degrade gracefully.
  • Real transactions Install, remove and upgrade execute actual system changes via dnf5 / dnf copr / flatpak — with confirmation first.
  • Sync export/import Back up the installed package set as a versioned JSON file and reinstall from it on a fresh system.
